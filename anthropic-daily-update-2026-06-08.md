## Claude Code

**Five releases in window**, source-of-truth [github.com/anthropics/claude-code/releases](https://github.com/anthropics/claude-code/releases) and the consolidated [CHANGELOG.md](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md). Lockstep `claude-agent-sdk-typescript` versions (v0.3.163 → v0.3.168) and lockstep `claude-agent-sdk-python` (v0.2.90 → v0.2.93) shipped alongside.

**v2.1.163 — 2026-06-04 21:52 UTC** ([release](https://github.com/anthropics/claude-code/releases/tag/v2.1.163)). Largest practitioner-relevant release in window:

- **`requiredMinimumVersion` and `requiredMaximumVersion` managed settings** — Claude Code refuses to start outside the allowed range and directs the user to an approved version. Useful for orgs pinning Claude Code in regulated environments.
- **`/plugin list`** with `--enabled`/`--disabled` filters. First proper enumeration command for the plugin surface added in v2.1.157.
- **Hooks: `Stop` and `SubagentStop` hooks can now return `hookSpecificOutput.additionalContext`** to give Claude feedback and keep the turn going **without being labeled a hook error**. The previous-only path (returning a non-zero status with feedback) flagged as an error in transcripts; this gives you a clean way to nudge the model from a hook. SDK parity in v0.3.163.
- **`/btw` "c to copy"** copies the raw markdown answer to clipboard, preserving formatting.
- **Skills: `\$` escape syntax** for a literal `$` before a digit in command bodies.
- **stdio MCP servers now receive the same `CLAUDE_CODE_SESSION_ID` as hooks/Bash on `--resume`** — previously a foot-gun for any MCP server that keyed state on session id and was resumed mid-flow.
- **`claude -p` hang-on-background-process fix:** previously hung forever if a backgrounded command never exited; background shells are now stopped ~5s after the result once stdin closes.
- **`claude -p` Bedrock/Vertex/Foundry `CI=true` fix:** no longer fails with "ANTHROPIC_API_KEY required".
- **Bash `$TMPDIR` regression fixed:** the override to `/tmp/claude-{uid}` was being applied to all commands instead of only sandboxed ones (regression in 2.1.154). Broke bazel and EDR-protected Go workflows.
- **Windows OneDrive / read-only "EEXIST: file already exists"** on session-env directory — fixed.
- **Org-managed permission rules** were not applying for the entire session when the managed-settings fetch completed during startup on a fresh config directory — fixed.
- **Hook `if: "Bash(...)"` conditions** now match against commands inside `$()` subshells and backticks; previously they fired on every Bash command containing `$()` or `$VAR`.
- **Deny rules on `~/...` paths** now block Bash commands that reference the path via `$HOME` — fixed.

**v2.1.165 — 2026-06-05 05:45 UTC** ([release](https://github.com/anthropics/claude-code/releases/tag/v2.1.165)). _Bug fixes and reliability improvements only_, no flagged user-facing changes.

**v2.1.166 — 2026-06-06 00:55 UTC** ([release](https://github.com/anthropics/claude-code/releases/tag/v2.1.166)). Second-largest release in window and the one to read closely:

- **`fallbackModel` setting configures up to three fallback models tried in order** when the primary is overloaded/unavailable; **`--fallback-model` now also applies to interactive sessions** (previously `-p`/headless only). Lets you set a quality-tier cascade (e.g. Opus 4.8 → Opus 4.7 → Sonnet 4.6) for resilience.
- **Glob pattern support in deny-rule tool-name position:** `"*"` denies all tools; allow rules reject non-MCP globs; **unknown tool names in deny rules warn at startup.** Closes a class of "I wrote `BashTool` instead of `Bash` and my deny rule silently does nothing" bugs.
- **Cross-session message security hardening:** messages relayed via `SendMessage` from other Claude sessions **no longer carry user authority** — receivers refuse relayed permission requests, and auto mode blocks them. _Important if you've built any inter-session orchestration: a child session can no longer impersonate the user to clear permission prompts in a peer session._
- **`MAX_THINKING_TOKENS=0`, `--thinking disabled`, and the per-model thinking toggle now disable thinking on models that think by default via the Claude API** (3P providers unchanged). Previously some default-thinking models ignored the disable flag. Cuts cost/latency for users who don't want thinking on Opus 4.8.
- **Auto-retry on fallback model:** Claude Code now retries a turn once on the fallback model when the API rejects with an unexpected non-retryable error; auth, rate-limit, request-size, and transport errors still surface immediately.
- **Stuck-on-bad-image fix:** recurring "image could not be processed" error and extra token usage when an unprocessable image was sent — fixed.
- **Background agent sessions inside git worktrees** were crash-looping with "No conversation found" when reopened from `claude agents` — fixed.
- **Managed settings:** `allowedMcpServers`/`deniedMcpServers` predicates were not matching when they used `${VAR}` references — fixed.
- **JetBrains IDE flicker** (IntelliJ/PyCharm/WebStorm 2026.1+) fixed by enabling synchronized output.
- **Kitty keyboard protocol Shift+non-ASCII drop fix** (WezTerm, Ghostty, kitty): Shift+ä → Ä no longer dropped.

**v2.1.167 — 2026-06-06 01:33 UTC** ([release](https://github.com/anthropics/claude-code/releases/tag/v2.1.167)). _Bug fixes and reliability improvements only._

**v2.1.168 — 2026-06-06 23:41 UTC** ([release](https://github.com/anthropics/claude-code/releases/tag/v2.1.168)). _Bug fixes and reliability improvements only._

## Research

**One substantive first-party publication in window, and it's a big one.** [**When AI builds itself**](https://www.anthropic.com/institute/recursive-self-improvement) by Marina Favaro and Jack Clark, under **The Anthropic Institute**. Timestamp on the page is not surfaced as a numeric publish field; Axios broke its embargo at Jun 4 16:00 UTC ([axios.com/2026/06/04/anthropic-warns-ai-build-successors](https://www.axios.com/2026/06/04/anthropic-warns-ai-build-successors)), so the post is effectively dated Jun 4. WSJ's "Anthropic Urges Global Pause" framing ([HN #48409735](https://news.ycombinator.com/item?id=48409735), 17 pts) and Telegraph's "Anthropic calls for global freeze" ([HN #48410437](https://news.ycombinator.com/item?id=48410437), 10 pts) hit Jun 5.

Concrete claims (with the company's own caveats noted in-line where they appear in the post):

- **>80% of lines merged into Anthropic's production codebase as of May 2026 were authored by Claude.** Pre–Claude Code research preview (Feb 2025) the share was "in the low single digits." (Anthropic leadership's [public BI estimate](https://www.businessinsider.com/anthropic-cfo-white-collar-jobs-changed-execution-oversight-2026-5) was 90%+; the 80% is the more conservative attribution-pipeline measure.)
- **8× lines-of-code/engineer/day vs. 2024.** Caveat from Anthropic in the post: "almost certainly an overstatement of the true productivity gain" — the chart shows two inflection points (mid-2025 when Claude began to run code, 2026 when models began autonomously working over longer horizons).
- **Internal poll, March 2026, n=130 researchers:** median self-reported 4× productivity uplift with Mythos Preview vs. no-AI baseline on the same work. Anthropic explicitly says the true uplift is probably lower, citing METR's [arxiv 2507.09089](https://arxiv.org/pdf/2507.09089) showing developers overestimate AI uplift.
- **Train-loop speedup benchmark (Claude makes a train script faster while preserving correctness):** May 2025 Claude Opus 4 averaged ~3× speedup; April 2026 Claude Mythos Preview ~52×. Skilled human researcher: ~4× in 4–8 hours.
- **Anthropic's automated weak-to-strong supervision project** ([alignment.anthropic.com](https://alignment.anthropic.com/2026/automated-w2s-researcher/)): Claude-powered agents recovered ~97% of the floor-to-ceiling gap (vs. 23% for two human researchers in ~1 week), over 800 cumulative agent-hours, ~$18k compute. Caveats Anthropic notes: didn't transfer cleanly to production-scale models; humans chose the problem and rubric.
- **Research-taste "next step" benchmark (n=129 moments cherry-picked where the human's choice had room to improve):** Opus 4.5 (Nov 2025) beat the human 51% of the time; Mythos Preview (Apr 2026) hit 64%. **On a control set of n=127 moments where the human's choice was already strong, models won only ~20%** — read this caveat before quoting the 64%.
- **Counterfactual class of work:** Apr 2026, Claude shipped 800 fixes that reduced a class of API errors by ~1000×; the engineer overseeing it estimated a human would have needed ~4 years.
- **Code review impact:** in retrospective analysis, an automated Claude review of every change to claude.ai would have caught ~⅓ of bugs behind past incidents before they reached production.
- **METR's task-horizon trend:** doubling roughly every 4 months (up from the earlier 7-month doubling). Mythos Preview can "work for at least 16 hours" per METR.

**Policy ask.** Anthropic's call is not for a unilateral pause — it's a call for the verification infrastructure that would let multiple labs verifiably pause together. Direct quote-as-paraphrase: Anthropic would slow or temporarily pause **if** other developers at or near the frontier also did so verifiably, and the post commits The Anthropic Institute to build the systems "that a credible slowdown or pause would require." This is framed in opposition to a unilateral pause, which the post argues "accomplishes much less: it would change who the front-runner is, but it would not create the wider deliberative process that is currently missing." Jack Clark in Axios: Anthropic plans to engage lawmakers in the coming months.

_Why it matters to an applied engineer:_ if you read past the headline framing, the post is also the most data-rich public statement Anthropic has made about how its own engineering practice has changed. Three operational signals: (1) **human code review has become the binding bottleneck inside Anthropic** ("as we've begun to push more code around the organization, human code review has become a new bottleneck" — citing Amdahl's law). If your team has hit the same wall, the v2.1.166 automated `Claude` review story and `fallbackModel` resilience pattern are first-party validations of the architecture you'd build. (2) **Internal model adoption pattern:** code-quality parity claim is "Claude-written code was somewhat worse than human-written at Anthropic in late 2025, roughly at parity today, expected to be better within the year." That's a more aggressive timeline than most third-party benchmarks would suggest. (3) **The "good no" path:** Anthropic explicitly publishes that benchmarks like SWE-bench have saturated and that the doubling time on task length has accelerated 7→4 months — useful evidence to point at when an internal stakeholder argues "AI plateaued."
